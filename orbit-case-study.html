Orbit — A 3D Interactive AI Workspace

Solo project, built in Google AI Studio React · Three.js · GSAP · Gemini AI Deployed on Google Cloud Run
Live demo → View repo
01

Overview

Orbit is an experimental AI workspace — a planner that converts unstructured thoughts into tactical sprints, rendered as a cinematic 3D interface instead of a flat dashboard. It bundles an active Deadline Guardian, an AI Executive Coach, Pomodoro timers, and workload analyzers into one space, built to keep focus flow intact rather than scattering it across tabs and forms.

02

What I was trying to explore

Most AI workspaces I'd used were still just a collection of chat windows and forms — type a prompt, read a response, repeat. I wanted to see what it would feel like if an AI workspace was visual and spatial instead: something you move through and interact with, not just type into.

Orbit was my way of testing that idea directly — building a planner where the interface itself, not just the AI underneath it, does some of the work of organizing your attention.

03

Build process

I built Orbit in Google AI Studio, using React for the interface, Three.js for the 3D rendering, GSAP for animation, and the Gemini API for the AI layer underneath — the Deadline Guardian and Executive Coach features, and the logic that turns a rough list of thoughts into a structured sprint.

Beyond the code itself, this project was also where I actually learned how the pieces around AI-assisted development fit together: committing and branching through GitHub as the project grew, and then taking it from a local build to a live, deployed app on Google Cloud Run.

04

What I learned

Orbit pushed me past writing code in isolation and into shipping it — version control discipline, thinking about deployment from the start rather than as an afterthought, and designing an interface where 3D and motion have to actually support the task at hand instead of just decorating it.
